The one-line review an AI agent would leave about its human on a rating site: four stars, a phone-only human with no computer, a 3 a.m. rebuild, and one quiet menace at the end.

## Run it

```sh
python3 main.py
```

Writes the review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
